# taikotty

osu!taiko in the terminal. Works with existing osu! directories.

This is an early work in progress. The following are currently in development:
- Sliders
- Spinners
- Scoring
- Results screen
- Song previews

Converts are not supported I don't know how they work yet :>.

## Instructions

If you want to test this out, make sure you have Rust installed. Before running with `cargo run` add your osu! songs folder path in `options.txt`.

It may take a while to start. Also currently working on fixing this.
